# App Store copy — Boat Manager 1.6.2

A one-fix release on top of 1.6.1, from branch `release-1.6.2` in the app
repo (built from tag `Release1.6.1`). Source of truth for the in-app What's
New is `Boat_Manager_2App.swift` on that branch; keep the two in step.

The fix: `Items.csv`'s dates were parsed with the device's short date style,
so in any region that writes the day first the file failed to decode and a
new user's maintenance library was empty. Existing users are unaffected:
their library was seeded long ago, or came from iCloud.

Paste-ready: `whats-new-1.6.2.txt` and `promotional-text-1.6.2.txt` (the
1.6.1 promotional text without "New in 1.6.1:").

App Review notes, first paragraph: "1.6.2 fixes one bug: the starter
maintenance library was not created for new users whose device region writes
dates day-first. No new permissions, no data model change."
